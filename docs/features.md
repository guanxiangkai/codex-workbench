# 工作台功能手册

## 定位与边界

工作台把散落在本机的账户、配置、模型、技能与已审核知识汇集到一个 Codex MCP Apps 入口。界面使用“账户与配置 / 能力与知识”两组导航，目前有六个模块。浏览器预览用于开发；最终使用效果取决于 Codex 宿主的 MCP Apps 支持。

工作台以受控读取为主。搜索、筛选、展开详情不会创建账户、购买套餐或调用付费生成接口。设置默认 Codex 账户是明确的写操作：保存本机偏好并影响新会话；不会更改已有会话或官方登录。可选模型网关是独立工具，不随页面启动。

## 六个模块

| 模块 | 用户能做什么 | 数据与限制 |
| --- | --- | --- |
| Codex 账户 | 不切换当前登录账户，也能使用已接入其他账户的额度；查看额度、重置时间和使用状态，选择新会话默认额度来源 | 登录身份与额度来源分开；官方未提供的字段保持未知，不把未知额度显示成零 |
| 其他账户 | 按平台浏览账户、搜索、查看用量、发起后台刷新 | 未配置账户的平台不展示；MiniMax 与智谱 BigModel 用不同颜色辅助识别，状态仍有文字 |
| 配置中心 | 按目录与类型缩小范围，即时搜索配置，查看普通字段及受控敏感字段 | 没有标签和平台筛选；不会提供一般配置的增删改表单 |
| 模型目录 | 按供应商和模型能力筛选，查模型详情与调用验证状态 | “验证通过”必须来自匹配当前配置的实际调用记录；HTTP 200 或账户可用不能替代生成成功 |
| 技能助手 | 搜索技能名称、说明，按技能类型筛选，查看详情 | 显示发现结果与可用状态；不是自动安装技能的入口 |
| 知识中心 | 按知识范围筛选，即时搜索并查看已审核知识 | 依赖外部知识适配器；缺少适配器时显示来源不可用 |

### 账户与用量

账户额度按照来源提供的窗口展示，保留重置时间、套餐和到期等已提供信息。官方没有返回的内容不推算。用量刷新进入后台队列，不阻塞页面，也不因来源短暂失败抹掉上一份成功数据。头像与昵称优先取已确认资料，不用邮箱冒充昵称。

### 配置中心

左侧目录用于定位，右侧展示当前目录的配置。搜索输入后动态筛选，不需要查询按钮；配置类型选择和关键词共同生效。桌面搜索框保持 280px，不随选项文本变长。工具栏本身没有整行背景，不固定在页面顶部。

目录面板随页面滚动，到顶部后停住；标题与目录数量固定在面板内部，仅目录树滚动。小屏下改为普通文档流中的有限高度目录区域，避免遮挡列表。列表数量与搜索筛选同行显示，反映当前结果。

普通字段与敏感字段分组展示。敏感字段通过浏览器临时密钥与加密信封受控读取；页面隐藏或离开时清理解密结果。此设计不代表浏览器剪贴板能自动撤回，也不能替代用户自己的保险库安全策略。

### 模型验证

状态绑定模型标识、连接地址、协议、能力与凭据引用。配置改变后旧验证不会直接沿用，同一凭据下其他模型也不继承结果。异步生成必须拿到最终产物后登记；未调用、取消或只查询账户不算验证。登记命令是记录接口，真实性由实际调用与结果核验负责。

### 搜索与详情

各模块直接过滤已取得的数据，数量同步更新。知识范围、技能类型等选择必须参与实际过滤。详情保留列表上下文；返回后继续当前浏览。无结果明确显示“没有匹配项”，与“来源不可用”和“尚在加载”区分。

## 快照与刷新

打开页面先读取内存与本机快照，后台定期采集来源。关注度按最近 15 分钟是否访问判断；默认活跃/空闲间隔如下：

| 模块 | 活跃 | 空闲 |
| --- | --- | --- |
| Codex 账户 | 1 分钟 | 5 分钟 |
| 其他账户、配置 | 5 分钟 | 30 分钟 |
| 模型、知识 | 10 分钟 | 60 分钟 |
| 技能 | 30 分钟 | 360 分钟 |

最多同时采集三个模块，同模块不重复并发。失败保留旧快照；第一次尚未采集成功时不能把统计误报为零。列表全量展示当前筛选结果，没有分页。

## 配置与可扩展性

账户与模型支持逐条 JSON 分片，也兼容原 catalog 文件；重复 ID 报错，不按读取顺序覆盖。拆分降低并发修改同一大文件的概率，写入方仍需原子写入和版本检查。技能、知识、配置等按各自权威来源读取，并非都变成账户 HTTP 接口。格式与迁移方法见 [适配器契约](adapters.md)。

## 当前不包含什么

执行记录已从当前导航移除，只保留 [讨论设计](execution-records-discussion.md) 和恢复分支。资源中心和分页也保留在独立分支。公开代码不附带个人账户、凭据、知识内容或运行数据库；也不包含完整私有保险库实现。项目是独立集成工具，非 OpenAI 官方产品；当前未授予源码开源许可。
