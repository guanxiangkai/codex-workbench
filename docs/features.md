# 功能范围

工作台标题独占第一行，下方直接显示“Codex 账户”“其他账户”“模型服务”三个标签页，不显示模块分组标题。三个页签字号为 15px，选中背景分别为绿色、蓝色、紫色。Codex 账户卡片不提供“更新资料”按钮。配置中心、知识中心页面已退役；知识目录仍由 `knowledge_list`/`knowledge_detail` 独立只读接口提供。工作台不提供配置目录、详情、解密或编辑工具。技能和插件由 Codex 原生入口展示，工作台不提供技能页和后台技能采集。页面不读取或创建工作记录、项目或工作计划，也不提供独立工具连接页签。

所有账户与连接数据保持在其既有权威位置。工作台只读取业务状态与用量投影；配置由独立模块维护，内部消费者按引用使用秘密，页面和发布包不包含秘密。Codex 切换更新默认账户选择，会话执行端读取该选择；账户额度仍由官方查询结果确定。

模型服务支持发现官方新模型并验证可用性，区分可用、余额不足、需要付费、权限受限和暂时失败等状态。列表按能力、供应商和状态组合筛选后分页。刷新期间显示进度，结束后仅显示约 10 秒的消息；重新打开页面不重复提示历史刷新结果。
