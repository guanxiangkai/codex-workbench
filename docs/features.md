# 功能范围

1.0.0 工作台分为“账户管理”和“服务目录”：前者提供 Codex 账户、平台账户，后者提供模型服务。配置中心、知识中心页面已退役；知识目录仍由 `knowledge_list`/`knowledge_detail` 独立只读接口提供。工作台不提供配置目录、详情、解密或编辑工具。技能和插件由 Codex 原生入口展示，工作台不提供技能页和后台技能采集。页面不读取或创建工作记录、项目或工作计划，也不提供独立工具连接页签。

所有账户与连接数据保持在其既有权威位置。工作台只读取业务状态与用量投影；配置由独立模块维护，内部消费者按引用使用秘密，页面和发布包不包含秘密。Codex 切换更新默认账户选择，会话执行端读取该选择；账户额度仍由官方查询结果确定。
